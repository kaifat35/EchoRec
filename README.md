# EchoRec

Простое приложение для записи **микрофона** в AAC/M4A на Android 9 (API 28) и новее, включая Android 16. Запись начинается только после нажатия пользователя и всегда сопровождается foreground-уведомлением. Готовый файл можно прослушать, удалить или передать через системное меню «Поделиться».

## Ограничение записи звонков

Обычное Android-приложение не может надёжно записывать голос собеседника на современных Android. `VOICE_CALL`, специальные разрешения и Shizuku не меняют этого: Shizuku является внешним сервисом и не даёт процессу приложения системный доступ к аудиопотоку. Поэтому Shizuku намеренно не включён в APK и приложение не делает ложных обещаний. Для записи разговоров необходима системная/OEM-программа или привилегированный компонент конкретной прошивки; универсального легального API для этого нет.

## Как работает приложение

* `MainActivity` запрашивает `RECORD_AUDIO` и, на Android 13+, разрешение на уведомления. Повторная проверка после возврата в приложение поддерживает изменение разрешений в настройках.
* `RecorderApp` — Compose-экран: показывает состояние разрешения, амплитуду и длительность записи, а также список файлов. Ошибки и результаты выводятся как Snackbar.
* `RecorderViewModel` создаёт `MediaRecorder` с источником `MIC`, контейнером MPEG-4 и AAC. Файлы сохраняются в `getExternalFilesDir(Music)`, поэтому дополнительное разрешение на хранилище не нужно. Он же управляет `MediaPlayer`, удалением и передачей `content://` URI через `FileProvider`.
* `RecordingService` существует только во время записи и публикует foreground-уведомление с типом `microphone`.

## Сборка и запуск

1. Откройте корень проекта в Android Studio и выполните Gradle Sync.
2. Соберите и установите модуль `app` на устройство Android 9+.
3. Нажмите «Разрешить» в карточке микрофона и затем круглую кнопку с микрофоном.
4. Нажмите кнопку паузы для паузы, «Остановить» — для финализации M4A. Не закрывайте запись принудительно: короткий незавершённый файл удаляется, чтобы не показывать повреждённый результат.
